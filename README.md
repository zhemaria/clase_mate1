# clase_mate1 · Matemáticas, Nivel 1: Iniciación y dominio numérico

Las **25 lecciones** del Nivel 1 de Matemáticas de GEDparaHispanos, en español y pensadas para el **alumno que estudia por su cuenta**, como preparación para el examen GED de Razonamiento Matemático. Cada lección explica paso a paso, trae ejemplos resueltos y práctica, y enlaza con su **interactivo** del repositorio [`algebra`](https://github.com/zhemaria/algebra).

## Empezar

- 🔁 **Todas las prácticas interactivas del nivel:** <https://zhemaria.github.io/algebra/n1-repaso.html>
- ▶️ **Primera lección:** <https://zhemaria.github.io/clase_mate1/leccion-1-1.html>
- 📝 **Examen de práctica de Matemáticas:** <https://zhemaria.github.io/examen/matematicas> (si estudias por tu cuenta, escribe `9999` como código de grupo)

## Cómo está organizado el repositorio

- `leccion-T-N.html (con guion)`: la lección N del tema T. Cada lección es un archivo HTML autosuficiente.
- Las secciones tienen anclas (`#s-…`); el informe del examen de práctica las usa para llevar al alumno a la parte exacta que debe repasar.
- Los interactivos de cada lección están en `algebra` con el nombre `n1-lT-N.html`.
